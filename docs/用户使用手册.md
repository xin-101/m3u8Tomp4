# m3u8ToMp4 用户使用手册

## 安装/运行

### 方式一：开箱成品(release)

```
release/
├── m3u8ToMp4.exe  # 双击运行
├── ffmpeg.exe       # 已内置, 无需安装
├── README.txt
└── config/
```

无需安装 Python。双击 `m3u8ToMp4.exe` 即可。

### 方式二：源码运行

```bash
pip install -r requirements.txt
python main.py
```

## 基本操作

1. 点击 **新建任务** → 输入 M3U8 地址(或选择本地 .m3u8)→ 自动解析并展示视频信息(分辨率/码率/时长/音频/分片数/加密)→ 确认后创建任务。
2. 右侧 **任务列表** 点 **开始** 开始下载/转换。
3. **暂停** 暂停当前任务(分片级断点, 进度落盘)。再次点 **开始** 自动续传。
4. **删除** 删除任务(同时清理断点缓存)。
5. 顶部 **历史记录** 页：搜索/删除/打开目录/重新下载/清空。
6. 顶部 **设置**：下载目录、最大并发任务、下载限速、FFmpeg 路径、自动转换 MP4、开机启动。

## 断点续传

- 下载中途暂停/关闭程序, 进度会写入 `download_cache/<任务id>/state.json`。
- 重新启动程序后, 未完成任务自动出现在任务列表(状态设为"等待"), 点 **开始** 即从断点继续。
- 完成后缓存自动清理。

## 浏览器插件

1. 源码自带 `browser-extension/` Chrome 扩展(MV3)。
2. 打开 `chrome://extensions` → 开启"开发者模式" → "加载已解压的扩展程序" → 选择 `browser-extension/`。
3. 启动客户端后, 浏览器插件可通过右键 "发送到 m3u8ToMp4" 或弹窗提取页面 m3u8 地址, 提交给客户端自动建任务。
4. 客户端 API 地址：`http://127.0.0.1:18888`（GET /api/health, POST /api/task）。

## 限速

设置中选择：不限速 / 500KB/s / 1MB/s / 5MB/s / 10MB/s。所有任务共享一个令牌桶限速器。

## 加密提示

- 检测到 `#EXT-X-KEY: METHOD=AES-128`：普通密钥可自动解密下载(合法授权场景)。
- 检测到 DRM(如 SAMPLE-AES/Widevine): 程序会拦截并提示"该视频受到加密保护, 需要合法授权", 不提供破解。

## 常见问题

- **FFmpeg 缺失**：确保 `resources/ffmpeg.exe`(源码版)或 release 目录下的 `ffmpeg.exe` 存在；也可在设置中指定路径。
- **下载的 ts 无法转换**：程序默认 `-c copy` 快速封装, 失败会自动回退 libx264/aac 重编码。
- **跨盘符速度**：日志速度按实时统计, 会随网络/磁盘波动。
